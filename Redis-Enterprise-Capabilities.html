Deployment models

Redis SoftwareSelf-managed
Enterprise-grade Redis you run in your own data center or cloud account. Linear scalability, HA, backups & recovery, predictable performance, and 24/7 support.
Redis CloudFully managed
Database-as-a-service on AWS, Google Cloud & Azure. Enterprise by default — all Redis Software features plus instant failover, automated ops, and 24/7 monitoring.
Redis for KubernetesOperator
The Redis Enterprise operator brings every Software capability to any CNCF-conformant cluster via CRDs (REC/REDB) and GitOps-friendly, Kubernetes-native workflows.

Active-Active geo-distribution

Multi-primary, conflict-free, globally distributed
Built on conflict-free replicated data types (CRDTs). Applications read and write the same dataset from any region with local, sub-millisecond latency — and keep working even if an entire cluster goes offline.
Multi-primary replication — Every participating cluster hosts a writable primary; connect to the closest region for near-local latency.
Automatic conflict resolution — CRDTs resolve concurrent writes deterministically with no application-side logic.
Strong eventual consistency — Vector clocks converge replicas to one state; optional causal consistency preserves operation order.
Syncer — Keeps a replication backlog and uses partial syncs (or a full sync on loss) to keep clusters consistent.
Disaster recovery — Geo-redundancy provides built-in DR and accelerated read access for distributed users.
